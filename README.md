# Wine Quality Analytics Dashboard

## Alcoholic Beverage Sector Project

This project analyzes the Wine Quality Dataset using Python, Data Analysis, Visualization, and Machine Learning.

### Project Features

- Dataset Overview
- Exploratory Data Analysis (EDA)
- Interactive Streamlit Dashboard
- Wine Quality Filtering
- Machine Learning Classification
- Model Accuracy Comparison

### Machine Learning

The project uses a 75% training and 25% testing split.

The tested algorithms include:

- Logistic Regression
- Decision Tree
- Random Forest
- K-Nearest Neighbors
- Support Vector Machine

### Technologies Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
- Streamlit

### Files

- `app.py` – Main Streamlit application
- `winequality.csv` – Wine quality dataset
- `requirements.txt` – Required Python libraries

### Project Output

The application provides data analysis, interactive visualizations, and wine quality prediction.

## Streamlit Application

The project is deployed using Streamlit Community Cloud.
